# Recorded demonstration format

The optional static replay file is `frontend/public/recordings/demo.json`.
It is not shipped in this checkout. The connected bridge can separately serve
the committed open-research run in `discolab/results/recorded-open-question/`.

Use the [authoritative format and export procedure](../../docs/RECORDING_FORMAT.md)
before adding a static replay. Source state, activity and experiment results
must come from one real run; the UI must label replayed evidence `RECORDED`.
