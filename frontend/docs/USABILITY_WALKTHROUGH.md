# Usability walkthrough — Noesis workspace

The [fixture-based usability walkthrough](../../docs/USABILITY_WALKTHROUGH.md)
records desktop and mobile checks, screenshots and accessibility observations.
Its fixture numbers are not research findings and it does not constitute a
hosted live-run acceptance test. For a current question-to-report check, use
the [demo runbook](../../docs/DEMO_RUNBOOK.md).
